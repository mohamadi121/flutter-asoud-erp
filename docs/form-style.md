# قرارداد ثابت استایل فرم‌ها

مرجع مصوب کاربر: فرم ثبت «اشخاص و شرکت‌ها». این قرارداد برای فرم‌های جدید و فرم‌های ایجاد/ویرایش پرسنل لازم‌الاجراست.

- فرم‌ها از `AsoudFormPage`، `AsoudFormSection` و فیلدهای `asoud_form.dart` استفاده می‌کنند.
- گروه‌های فرم کارت‌های کشویی هستند؛ در ابتدا بسته‌اند و با بسته‌شدن مقدار فیلدها حفظ می‌شود.
- فاصله، گردی، رنگ، تایپوگرافی و نوار ذخیره/انصراف از اجزای مشترک می‌آیند. بازنویسی محلی این ویژگی‌ها مجاز نیست.
- انتخاب‌ها از `AsoudFormDropdown`، تاریخ از `AsoudFormDateField` و متن از `AsoudFormField` استفاده می‌کنند.
- صفحات نمایش اطلاعات با فرم ویرایش جدا هستند. نمایش و دکمه‌ها از زبان بصری پرونده پرسنلی استفاده می‌کنند.
- قفل استایل به معنی ثابت‌بودن طراحی است، نه غیرفعال‌کردن فیلد یا جلوگیری از ویرایش اطلاعات.
- تغییر ظاهر مرجع تنها با درخواست صریح کاربر و به‌روزرسانی تست تصویری فرم‌ها انجام می‌شود.
- اعتبارسنجی سمت سرور و کنترل دسترسی مستقل از استایل حفظ می‌شوند؛ داده فقط پس از موفقیت ذخیره از فرم خارج می‌شود.
